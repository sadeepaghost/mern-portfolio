# MERN Portfolio Requirements

## Project Purpose

Build a full-stack portfolio application that presents my skills,
projects and experience while allowing me to manage content through
a protected admin dashboard.

## User Types

### Visitor

A visitor can view my profile, skills, projects and contact information.

### Recruiter

A recruiter can review my strongest projects, download my CV,
visit my GitHub profile and contact me.

### Administrator

The administrator can log in and manage portfolio content.

## Initial Features

- Responsive home page
- About section
- Skills section
- Project listing
- Detailed project pages
- Contact form
- Admin authentication
- Project management dashboard

## Future Features

- Technical blog
- GitHub integration
- Portfolio analytics
- AI portfolio assistant
